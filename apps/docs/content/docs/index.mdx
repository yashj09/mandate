Mandate is bounded delegation for AI agents. You own a smart account. You decide which contract calls the agent may make, how much USDC may leave per transaction and per day, and which actions need a tap on your Ledger. The agent plans and executes inside those limits. The contract enforces them, not the model.

## How a request flows

```mermaid
flowchart TB
  U[You: chat or MCP] --> A[The model drafts an intent]
  A --> P[Deterministic planner builds typed steps]
  P --> S[Simulation against live chain state]
  S --> X[Executor sends each step]
  X -->|inside caps| MA[MandateAccount.execute]
  X -->|irreversible| L[Ledger clear-signs the approval text]
  L --> MG[MandateAccount.executeWithGuardian]
  MA --> C[Compound v3 on Base Sepolia]
  MG --> B[CCTP burn, payment on Arc]
```
